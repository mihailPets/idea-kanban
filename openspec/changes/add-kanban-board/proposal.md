## Почему

Выполнить тестовое задание Idea Platform в виде канбан-доски, которую ревьюер может запустить локально или открыть по публичной ссылке.

## Что меняется

- Отображение исходных задач в четырёх колонках из макета Figma.
- Поиск по тексту и датам, обозначение просрочки, создание, редактирование и удаление задач, перенос указателем и клавиатурой.
- Сохранение изменений в браузере и публикация проверенной статической сборки на GitHub Pages.

## Capabilities

### New Capabilities

- `kanban-board` — отображение задач, управление ими, хранение изменений и проверки перед публикацией.

### Modified Capabilities

## Область изменений

Приложение на Webpack, React и TypeScript, совместимое с Node.js 18.18.0, тесты и сценарий публикации на GitHub Pages.
