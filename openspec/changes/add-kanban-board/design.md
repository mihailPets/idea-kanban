## Контекст

Канбан-доска работает в браузере как статическое React-приложение. Метки времени в исходном JSON указаны в миллисекундах. Тестовое задание закрепляет Node.js 18.18.0 и Webpack.

## Цель и границы

Воспроизвести макет Figma и сделать операции с задачами предсказуемыми, доступными и проверяемыми. Серверное хранилище, синхронизация вкладок, ручной порядок карточек и общая дизайн-система выходят за рамки задания.

## Решения

### ADR 1 — Единый список задач и вычисляемые колонки

Список хранится в состоянии React. Правила операций реализованы чистыми функциями. Данные проверяются при чтении из хранилища. Отдельные списки для каждой колонки упростили бы рендер, но усложнили бы перенос, сохранение и проверку уникальности ID. При текущем объёме данных колонки вычисляются при рендере.

### ADR 2 — Сравнение календарных дат по местному времени

Отображение, поиск, форма и проверка просрочки используют общие функции работы с местной датой. Сравнение по UTC или по длительности суток могло бы дать другой результат, чем дата, которую видит пользователь. Дата на экране зависит от часового пояса браузера. При сохранении задачи неизменённые даты сохраняют исходные метки времени.

### ADR 3 — При переносе меняется только статус

Датчики dnd-kit обрабатывают ввод указателем и клавиатурой. У карточки отдельная ручка переноса. Каждая колонка служит целью переноса, а карточки после переноса располагаются по правилам сортировки. Нативный HTML Drag and Drop сократил бы число зависимостей, но потребовал бы отдельной реализации управления с клавиатуры.

## Ограничения

Если сохранённые данные некорректны, доска загружает исходный JSON. Если хранилище недоступно, изменения остаются в памяти и интерфейс сообщает об этом. Поддержка Node.js 18 завершена, но эта версия нужна для совместимости с заданием. GitHub Pages отдаёт сборку из подпапки репозитория.
