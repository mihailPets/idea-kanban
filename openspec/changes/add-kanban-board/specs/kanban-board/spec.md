## Purpose

Описать правила работы канбан-доски, обработки дат и публикации приложения.

## ADDED Requirements

### Requirement: Отображение задач
Доска обязана (SHALL) показывать четыре статуса в порядке из Figma и сортировать задачи в колонке по времени начала, а при равенстве по ID. Минимальная ширина составляет 768 px, максимальная 1920 px. На более широком экране доска выравнивается по центру.

#### Scenario: Первый запуск
- **WHEN** сохранённый список отсутствует
- **THEN** доска показывает 17 исходных задач в соответствующих колонках.

### Requirement: Даты и поиск
Доска обязана (SHALL) сравнивать даты по местному календарю, обозначать просрочку вне Done красной рамкой и видимым предупреждением с доступным текстом. Поиск по описанию выполняется без учёта регистра. Корректная дата ищется по точному совпадению с началом или окончанием задачи.

#### Scenario: Дедлайн сегодня
- **WHEN** дедлайн приходится на текущую местную дату
- **THEN** карточка не отмечается как просроченная.

#### Scenario: Поиск при открытой форме
- **WHEN** пользователь открывает форму создания или редактирования
- **THEN** поле поиска сохраняет текущий фильтр и доступно только для чтения до сохранения или отмены.

### Requirement: Действия с задачами
Доска обязана (SHALL) позволять создавать задачи в To Do, а редактировать и удалять во всех колонках. Новая задача получает уникальный числовой ID. Неизменённые даты сохраняют исходные метки времени.

#### Scenario: Ошибка в черновике
- **WHEN** описание пустое, календарная дата некорректна или дедлайн раньше начала
- **THEN** доска сохраняет прежний список и черновик, отмечает первое ошибочное поле, связывает его с конкретным сообщением и переводит на него фокус.

### Requirement: Перенос между колонками
Доска обязана (SHALL) поддерживать перенос указателем и клавиатурой в любую колонку, включая пустые. При успешном переносе меняется только статус. Кнопки действий карточки работают независимо от ручки переноса.

#### Scenario: Отмена переноса
- **WHEN** пользователь отменяет перенос или сбрасывает карточку вне колонки
- **THEN** список задач остаётся прежним.

### Requirement: Локальное хранение
Доска обязана (SHALL) сохранять изменения, проверять весь восстановленный список и работать в памяти при недоступности хранилища.

#### Scenario: Удалены все задачи
- **WHEN** сохранённый список представляет собой пустой массив
- **THEN** после обновления страницы отображаются четыре пустые колонки.

### Requirement: Проверка и публикация
Проект обязан (SHALL) работать на Node.js 18.18.0 и предоставлять необходимые команды npm. README содержит подтверждённый публичный адрес GitHub Pages и путь к тесту просрочки. До публикации workflow проверяет unit-тесты, production-сборку и браузерные сценарии.

#### Scenario: Публикация в подпапке репозитория
- **WHEN** пользователь открывает публичный URL GitHub Pages или обновляет страницу
- **THEN** доска и все ресурсы сборки загружаются из подпапки репозитория.
